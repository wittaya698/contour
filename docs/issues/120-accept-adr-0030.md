# 120 — Accept ADR 0030

**Type:** HITL · **Source:** ADR 0030, the tracer bullet — [topics label a model for finding](../adr/0030-topics-label-a-model-for-finding.md)

## What to build

ADR 0030 used by hand and given its verdict, in throwaway copies of the spaces.
Start the lobby pass and answer it, striking one word. Filter the lobby, and ask
Desktop *which models are creatures?*. Make a new space and take it to its first
green build in an unattended run; see the proposal wait, a request refused, and
the answer applied. Ask for topics again and check the struck word is not
offered. Release one model and read its topics out of the `.glb`.

**Accept, amend or withdraw** ADR 0030 on what that shows — in particular
whether a topic proposal blocking a space (decision 6) is a wait the user is
glad of.

## Acceptance criteria

- [ ] The tracer bullet run end to end, each step as written or the difference recorded (in ADR 0030's status)
- [ ] The vocabulary after the lobby pass has no two spellings of one word
- [ ] ADR 0030's status says accepted, amended or withdrawn, with the evidence
